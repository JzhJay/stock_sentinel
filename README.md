# A 股智能选股系统

基于公开行情数据，综合多种技术指标对沪深 A 股进行两轮量化评分：第一轮按 10 维度综合打分（**无硬门槛淘汰**）筛出 Top-10，第二轮 5 维度精选 Top-3，并给出止盈止损参考价位。

## 整体流程

```
股票列表(baostock)
   ↓
实时行情(新浪 hq.sinajs.cn)
   ↓
基础过滤（排除 ST / 停牌 / 涨跌停 / 价格越界）
   ↓
预筛选（实时行情快速打分，保留 Top-N 候选）
   ↓
历史 K 线获取（baostock 前复权日 K 线，120 天）
   ↓
【第一轮】10 维度技术指标评分（加权满分 100） → 初选 Top-10
   ↓
止盈止损预测（ATR + 支撑阻力 + 布林带）
   ↓
【第二轮】5 维度精选评分（加权满分 50） → 精选 Top-3
   ↓
综合分 = 初选分 + 精选分（满分 150）→ 最终排名输出
```

---

## 一、评分算法详解

### 总分计算方式

每个维度独立计算一个 **0\~10 的原始分**，再乘以该维度的权重系数，所有维度加权求和得到满分 100 的总分：

```
总分 = Σ (维度原始分 / 10 × 维度权重)
```

权重分配如下（可在 `config.py` 的 `SCORE_WEIGHTS` 中调整，总和必须 = 100）：

| 维度 | 权重 | 设计意图 |
|------|------|----------|
| 均线趋势 | 30 | 核心：均线向上发散 + 多头结构 |
| 筹码分布 | 25 | 核心：上方筹码越稀疏越优 |
| 相对低位 | 15 | 核心：横向比较处于相对低位 |
| MACD | 8 | 趋势/动量辅助加分 |
| 成交量 | 7 | 量价配合辅助加分 |
| 布林带 | 5 | 位置与突破辅助加分 |
| 动量 | 4 | 短期涨势辅助加分 |
| 换手率 | 3 | 活跃度辅助加分 |
| RSI | 2 | 超买超卖辅助 |
| KDJ | 1 | 金叉信号辅助 |

---

### 1. 均线趋势（权重 30，原始分 0\~10）

使用 MA5 / MA10 / MA20 / MA60 四条简单移动平均线，逐项叠加得分：

| 条件 | 得分 |
|------|------|
| 收盘价 > MA5 | +1 |
| 收盘价 > MA10 | +1 |
| 收盘价 > MA20 | +1.5 |
| 收盘价 > MA60 | +1.5 |
| MA5 近 3 日上行 | +1 |
| MA10 近 3 日上行 | +1 |
| MA5 > MA10 > MA20（多头排列） | +3 |

多头排列（短期均线依次在长期均线上方）是最核心的趋势确认信号，单独给予 3 分。最终取 \[0, 10\] 区间。

### 2. MACD（权重 8，原始分 0\~10）

计算标准 MACD（快线 EMA12，慢线 EMA26，信号线 EMA9）：

- **DIF** = EMA(12) − EMA(26)
- **DEA** = EMA(DIF, 9)
- **柱状线** = 2 × (DIF − DEA)

| 条件 | 得分 |
|------|------|
| 柱状线 > 0（多头区间） | +3 |
| 柱状线刚由负转正（金叉当日） | +3 |
| 柱状线较前一日递增 | +2 |
| DIF > DEA | +2 |

金叉当日同时满足"柱状线 > 0"和"由负转正"，可拿 6 分，反映强烈的趋势反转信号。

### 3. 成交量（权重 7，原始分 0\~10）

| 条件 | 得分 |
|------|------|
| 5 日均量 > 10 日均量 | +3 |
| 当日成交量 > 5 日均量 | +2 |
| 收盘价上涨 **且** 成交量放大（量价齐升） | +3 |
| 当日量 / 5 日均量 在 1.0\~3.0 倍（温和放量） | +2 |
| 当日量 / 5 日均量 ≥ 3.0 倍（异常放量，可能主力出货） | −2 |

关键点：温和放量配合价格上涨是健康信号；暴量反而扣分，因为可能意味着主力在高位派发。

### 4. 筹码分布（权重 25，原始分 0\~10）

使用最近 60 个交易日的量价数据，模拟筹码分布：

**算法原理**：将价格区间均匀分成 100 个分箱，每个交易日的成交量按三角分布（以收盘价为峰值）分配到对应价格分箱中。越早的交易日成交量会以 0.97 的衰减因子逐日递减，模拟筹码因换手而流失。

最终输出三个指标：

| 指标 | 含义 |
|------|------|
| `above_ratio` | 当前价上方筹码占比，越低上涨阻力越小 |
| `profit_ratio` | 获利盘比例（当前价下方筹码占比） |
| `concentration_90` | 90% 筹码所在价格宽度 / 当前价，越小筹码越集中 |

评分规则：

| 条件 | 得分 |
|------|------|
| 上方筹码 < 15% | +4 |
| 上方筹码 15%\~30% | +3 |
| 上方筹码 30%\~50% | +1 |
| 上方筹码 > 70% | −1 |
| 获利盘 60%\~85%（最健康区间） | +3 |
| 获利盘 50%\~60% | +2 |
| 获利盘 > 90%（过热） | +1 |
| 获利盘 < 30%（大面积套牢） | −1 |
| 筹码集中度 < 15% | +3 |
| 筹码集中度 15%\~25% | +2 |
| 筹码集中度 25%\~35% | +1 |

### 5. 动量（权重 4，原始分 0\~10）

衡量近期价格涨势强弱：

| 条件 | 得分 |
|------|------|
| 5 日涨幅 1%\~8%（温和上涨） | +4 |
| 5 日涨幅 0%\~1% | +2 |
| 5 日涨幅 > 8%（短期涨太多） | +1 |
| 10 日涨幅 2%\~15% | +3 |
| 10 日涨幅 0%\~2% | +1 |
| 当日阳线（收盘 > 开盘） | +3 |

温和、持续的上涨比急速拉升得分更高，体现"稳健上升趋势"的偏好。

### 6. 布林带（权重 5，原始分 0\~10）

使用 20 日布林带（中轨 = MA20，上下轨 = 中轨 ± 2 倍标准差），通过价格在带内的相对位置 `pos = (价格 − 下轨) / (上轨 − 下轨)` 评分：

| 条件 | 得分 |
|------|------|
| pos 在 0.4\~0.7（中轨附近偏强） | +5 |
| pos 在 0.1\~0.4（下轨附近反弹） | +4 |
| pos > 0.9（触及上轨，超买风险） | −2 |
| 价格向上突破中轨（前一日在中轨下，今日站上） | +5 |

突破中轨是重要的趋势转折信号，与中轨附近的位置分同等重要。

### 7. RSI（权重 2，原始分 0\~10）

使用 14 日 RSI，公式为 `RSI = 100 − 100/(1 + 平均涨幅/平均跌幅)`：

| 条件 | 得分 |
|------|------|
| RSI 30\~40（超卖反弹区，最佳买点） | +7 |
| RSI 40\~60（中性区间） | +5 |
| RSI 20\~30（深度超卖，可能仍在下跌） | +4 |
| RSI > 80（超买） | −3 |
| RSI 出现 V 形拐头（前日是近期低点） | +3 |

RSI 在 30\~40 给予最高分，因为此时既处于超卖区域又开始企稳，是概率最高的反弹买点。

### 8. KDJ（权重 1，原始分 0\~10）

标准 KDJ 指标（N=9, M1=3, M2=3），J = 3K − 2D：

| 条件 | 得分 |
|------|------|
| K 上穿 D（金叉当日） | +6 |
| K > D（金叉后持续） | +3 |
| J 值在 20\~80（健康区间） | +2 |
| J 值从 < 30 开始回升（低位拐头） | +2 |

KDJ 金叉是短线最敏感的买入信号之一，单日金叉给 6 分（含 K > D 的 3 分则共 6 分）。

### 9. 换手率（权重 3，原始分 0\~10）

| 条件 | 得分 |
|------|------|
| 当日换手率 2%\~8%（适中） | +5 |
| 当日换手率 1%\~2%（偏低但可接受） | +3 |
| 当日换手率 > 15%（异常活跃，风险信号） | −2 |
| 换手率 / 5 日均换手 在 1.0\~2.5 倍（温和放大） | +5 |
| 换手率 / 5 日均换手 ≥ 2.5 倍 | +1 |

换手率过高和过低都不理想——过低说明市场关注度不足，过高可能是短线资金博弈。

### 10. 相对低位（权重 15，原始分 0\~10）

用最近 120 日区间衡量股价横向位置：

```
相对位置 = (当前价 − 120日最低价) / (120日最高价 − 120日最低价)
```

评分偏好“不是最高位、也不是刀口最低位”的区间：

| 相对位置区间 | 得分 |
|-------------|------|
| 0.18 ~ 0.40 | 10 |
| 0.10 ~ 0.18 | 8 |
| 0.40 ~ 0.50 | 8 |
| < 0.10 | 4 |
| 0.50 ~ 0.60 | 5 |
| 其他 | 2 |

## 二、二次精选算法详解（Top-10 → Top-3）

第一轮 10 维度侧重于**信号强度**（趋势、动量、金叉等），但买入决策还需考虑**安全性和性价比**。第二轮用 5 个互补维度，从初选 Top-10 中精选最优 3 只。

### 精选分计算方式

与初选相同，每维度 0\~10 原始分，加权满分 50：

```
精选分 = Σ (维度原始分 / 10 × 维度权重)
综合分 = 初选分(满分100) + 精选分(满分50) = 满分 150
```

权重分配（可在 `config.py` 的 `ROUND2_WEIGHTS` 中调整，总和 = 50）：

| 维度 | 权重 | 设计意图 |
|------|------|----------|
| 风险收益比 | 12 | 入场性价比，止盈空间 / 止损空间越大越好 |
| 趋势稳定性 | 10 | 走势平滑度，稳健上升优于暴涨暴跌 |
| 量能持续性 | 10 | 持续放量优于脉冲式放量 |
| 乖离率 | 9 | 偏离均线程度，过远则回调风险高 |
| 多周期共振 | 9 | 日线 + 周线级别趋势方向一致 |

---

### 1. 风险收益比（权重 12，原始分 0\~10）

利用已计算好的止盈①/止盈②和止损价，计算加权风险收益比：

```
风险收益比 = (0.4 × |止盈①%| + 0.6 × |止盈②%|) / |止损%|
```

| 风险收益比 | 得分 |
|-----------|------|
| ≥ 3.0 | 10 |
| ≥ 2.5 | 8 |
| ≥ 2.0 | 6 |
| ≥ 1.5 | 4 |
| ≥ 1.0 | 2 |
| < 1.0 | 0 |

比值 ≥ 3 意味着每承受 1 元下跌风险可获得 3 元上涨空间，属于非常理想的入场时机。

### 2. 趋势稳定性（权重 10，原始分 0\~10）

对最近 20 日收盘价做**线性回归**，用 R²（决定系数）衡量趋势的平滑程度：

```
R² = 1 − Σ(实际值 − 拟合值)² / Σ(实际值 − 均值)²
```

R² 越接近 1，说明价格走势越接近一条直线（平滑上升/下降）；R² 低则说明价格震荡剧烈。

| 条件 | 得分 |
|------|------|
| R² ≥ 0.80 且斜率向上 | 10 |
| R² ≥ 0.60 且斜率向上 | 8 |
| R² ≥ 0.40 且斜率向上 | 6 |
| R² ≥ 0.20 且斜率向上 | 4 |
| 斜率向上但 R² 低 | 2 |
| 近期"更高的低点"数量（最多额外 +2） | +0.5/个 |

额外检查近 10 日是否持续出现"更高的低点"（higher lows），这是经典的上升趋势确认信号。

### 3. 乖离率 BIAS（权重 9，原始分 0\~10）

乖离率衡量当前价格偏离 MA20 的程度：

```
BIAS = (收盘价 − MA20) / MA20 × 100%
```

| BIAS 区间 | 得分 | 含义 |
|----------|------|------|
| 0% \~ 3% | 10 | 略高于均线，最安全的买入区间 |
| 3% \~ 5% | 7 | 偏强但仍健康 |
| 5% \~ 8% | 4 | 有一定回调风险 |
| > 8% | 1 | 严重超涨，追高风险大 |
| −2% \~ 0% | 5 | 接近均线，等待确认 |
| −5% \~ −2% | 3 | 偏弱，可能正在筑底 |
| < −5% | 1 | 远离均线，下跌趋势可能未止 |

BIAS 在 0\~3% 得分最高——股价刚刚站上均线，既确认了趋势又不存在追高风险。

### 4. 量能持续性（权重 10，原始分 0\~10）

检查最近 5 日的成交量是否持续高于 5 日均量，并用线性回归判断量能趋势：

| 条件 | 得分 |
|------|------|
| 4\~5 日高于均量 **且** 量能斜率向上 | 10 |
| 3 日高于均量 **且** 斜率向上 | 8 |
| 3 日高于均量 | 6 |
| 2 日高于均量 **且** 斜率向上 | 5 |
| 2 日高于均量 | 3 |
| 0\~1 日 | 1 |

持续放量比单日放量更可靠——单日脉冲可能是消息面驱动的一次性行为，持续放量说明场外资金在真实进场。

### 5. 多周期共振（权重 9，原始分 0\~10）

用日线级别的长短均线模拟多周期趋势：

- **日线级别**：收盘价 > MA5 > MA10（短期上升）
- **周线级别**：收盘价 > MA20 > MA60（中期上升，MA20 约等于周线 MA4）

| 条件 | 得分 |
|------|------|
| 日线 + 周线均上升 | 7 |
| 仅日线上升 | 4 |
| 仅周线上升 | 3 |
| MA20 近 3 日上行 | +1.5 |
| MA60 近 3 日上行 | +1.5 |

当日线和周线趋势方向一致时，形成"共振"效应，上涨的延续性和力度都会更强。

## 三、止盈止损预测算法

对最终入选的 Top 10 股票，综合三种方法计算止损和止盈参考价位。

### 核心指标：ATR（平均真实波幅）

ATR 衡量近 14 日的平均价格波动幅度：

```
真实波幅 TR = max(当日最高−最低, |最高−昨收|, |最低−昨收|)
ATR = TR 的 14 日简单移动平均
```

ATR 越大说明该股波动越剧烈，止盈止损区间应相应放宽。

### 止损价（自适应 ATR + 保护带）

| 方法 | 计算方式 | 逻辑 |
|------|----------|------|
| ATR 止损 | 现价 − `k × ATR` | `k` 随趋势强度变化（强趋势更宽，弱趋势更紧） |
| 支撑位止损 | 近 20 日最低价 × 0.99 | 跌破近期支撑即离场 |
| 布林下轨止损 | 布林带下轨值 | 跌破下轨意味着趋势可能反转 |

先取三者中的**最大值**作为候选止损价，再应用止损保护带：

- 最小止损幅度：3%
- 最大止损幅度：12%

用于避免止损过近（容易被噪声扫掉）或过远（风险收益比变差）。

### 止盈价（分两档）

**止盈①（短线目标）**：

| 方法 | 计算方式 |
|------|----------|
| ATR 目标 | 现价 + 1.5 × ATR |
| 布林中轨 | MA20 |

取二者中的较大值。若结果 ≤ 现价则回退到现价 × 1.03。

**止盈②（波段目标）**：

| 方法 | 计算方式 |
|------|----------|
| ATR 目标 | 现价 + 3.0 × ATR |
| 布林上轨 | MA20 + 2σ |
| 近期阻力 | 近 20 日最高价 |

取三者中的最大值。若结果 ≤ 止盈①则回退到止盈① × 1.03。

### 使用建议

- **止盈①** 适合短线操作，到达后可考虑减仓 50%
- **止盈②** 适合波段持有，到达后可考虑全部离场
- **止损价** 是刚性底线，跌破即无条件离场
- 触发**止盈①**后，建议启用移动止损（成本+缓冲 / MA10 / ATR跟踪取更高值）
- 所有价位仅为参考，实际操作应结合盘面变化

## 四、预筛选机制

在对所有股票做完整评分之前，先用实时行情做快速筛选以提升效率：

| 条件 | 预筛分 |
|------|--------|
| 涨跌幅在 −2% \~ +5% | +3 |
| 涨跌幅 > 0（当日上涨） | +2 |
| 成交额 > 5000 万（流动性充足） | +2 |
| 当日阳线（现价 > 开盘价） | +2 |
| 开盘价与昨收相差 < 3%（无大幅跳空） | +1 |

按预筛分降序排列，保留前 200 只进入详细评分阶段。

### 基础过滤规则

在预筛选之前，已排除以下股票：

- ST / \*ST / 退市警示股
- 北交所（8 开头）和科创板（688 开头）
- 股价 < 3 元 或 > 100 元
- 停牌（成交量 = 0）
- 涨跌停（涨跌幅绝对值 ≥ 9.8%）

## 快速使用

### 1. 创建并激活虚拟环境

```bash
python -m venv stock_sentinel
```

**Windows PowerShell：**

```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\stock_sentinel\Scripts\activate
```

**Windows CMD：**

```cmd
stock_sentinel\Scripts\activate.bat
```

**macOS / Linux：**

```bash
source stock_sentinel/bin/activate
```

激活成功后，终端提示符前会出现 `(stock_sentinel)` 前缀。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 运行选股

```bash
python main.py
```

运行结束后会在终端打印推荐排名，并在 `output/` 目录下自动保存两份 CSV 文件：
- `stock_picks_YYYYMMDD.csv` — 初选 Top-10
- `stock_final_YYYYMMDD.csv` — 精选 Top-3（含综合分和精选维度明细）

## 配置说明

编辑 `config.py` 可调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TOP_N` | 10 | 推荐股票数量 |
| `MIN_PRICE` / `MAX_PRICE` | 3.0 / 100.0 | 股价过滤区间（元） |
| `HISTORY_DAYS` | 120 | 历史 K 线天数 |

| `PRE_SCREEN_TOP` | 200 | 预筛选保留候选数量 |

| `ROUND2_WEIGHTS` | (见文件) | 精选各维度权重（总和 = 50） |
| `FINAL_TOP` | 3 | 二次精选最终推荐数量 |

### 如何新增评分维度

**初选维度**：
1. 在 `indicators.py` 中实现新指标的计算函数
2. 在 `scoring.py` 的 `score_stock()` 中添加新维度的 0\~10 评分逻辑
3. 在 `config.py` 的 `SCORE_WEIGHTS` 中添加新维度的 key，同时调低其他维度的权重使总和仍为 100

**精选维度**：
1. 同样在 `indicators.py` 中实现计算函数
2. 在 `scoring.py` 的 `score_stock_round2()` 中添加评分逻辑
3. 在 `config.py` 的 `ROUND2_WEIGHTS` 中添加 key，调整权重使总和仍为 50

## 输出文件字段说明

程序默认输出两份文件（`output/stock_picks_YYYYMMDD.csv`、`output/stock_final_YYYYMMDD.csv`），核心字段如下：

- `总分`：第一轮 10 维度加权分（满分 100）
- `精选分`：第二轮 5 维度加权分（满分 50，仅 final 文件）
- `综合分`：`总分 + 精选分`（满分 150，仅 final 文件）
- `止损% / 止盈1% / 止盈2% / 移动止损%`：导出时会格式化为带 `%` 的字符串，便于直接阅读
- `移动止损触发价 / 移动止损价 / ATR止损系数`：用于执行触发后的跟踪风控
- `信号摘要`：按阈值规则自动拼接的标签文本（如“均线多头 | MACD偏多 | 量价配合”）
- `R2_...`：第二轮各维度原始分（0~10，仅 final 文件）

## 运行与排障建议

- 首次运行前确认本机网络可访问 `hq.sinajs.cn` 与 `baostock` 数据源。
- 代码已在 `config.py` 设置 `NO_PROXY=*`，用于避免系统代理导致行情请求失败；如你依赖代理访问，请按实际网络环境调整。
- `get_all_stocks()` 会向前回退最多 7 天寻找最近交易日股票列表，非交易日运行通常仍可得到结果。
- 若出现“过滤后没有符合条件的股票”，优先检查：是否处于极端行情日、`MIN_PRICE/MAX_PRICE` 是否过窄、或网络返回数据是否不完整。
- 当前版本不做硬门槛淘汰；若结果不理想，优先通过 `SCORE_WEIGHTS` 调整排序侧重点。

## 已知限制与优化方向

- `fetch_and_score()` 当前按股票逐只串行拉取历史 K 线，`MAX_WORKERS` 尚未在主流程启用；大样本场景可考虑引入并发抓取。
- 移动止损为“触发后执行”的规则提示，当前脚本仍是单次离线计算，不会自动做盘中动态更新。
