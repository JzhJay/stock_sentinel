# A 股智能选股系统

基于公开行情数据，综合多种技术指标对沪深 A 股进行量化评分，自动选出推荐次日买入的前 10 只股票，并给出止盈止损参考价位。

## 整体流程

```
股票列表(baostock)
   ↓
实时行情(新浪 hq.sinajs.cn)
   ↓
基础过滤（排除 ST / 停牌 / 涨跌停 / 价格越界）
   ↓
预筛选（实时行情快速打分，保留 Top-N 候选）
   ↓
历史 K 线获取（baostock 前复权日 K 线，120 天）
   ↓
9 维度技术指标评分（加权满分 100）
   ↓
止盈止损预测（ATR + 支撑阻力 + 布林带）
   ↓
排名输出 + CSV 保存
```

---

## 一、评分算法详解

### 总分计算方式

每个维度独立计算一个 **0\~10 的原始分**，再乘以该维度的权重系数，所有维度加权求和得到满分 100 的总分：

```
总分 = Σ (维度原始分 / 10 × 维度权重)
```

权重分配如下（可在 `config.py` 的 `SCORE_WEIGHTS` 中调整，总和必须 = 100）：

| 维度 | 权重 | 设计意图 |
|------|------|----------|
| 均线趋势 | 15 | 趋势为王，多头排列是最强持续信号 |
| 成交量 | 13 | 量在价先，放量验证不可或缺 |
| MACD | 12 | 趋势 + 动量双重确认 |
| 筹码分布 | 12 | 上方抛压直接影响买点时机 |
| 动量 | 10 | 近期涨势强弱 |
| 布林带 | 10 | 位置分析 / 突破回踩 |
| 换手率 | 10 | 活跃度 / 流动性确认 |
| RSI | 9 | 超买超卖辅助 |
| KDJ | 9 | 金叉 / 超卖信号辅助 |

---

### 1. 均线趋势（权重 15，原始分 0\~10）

使用 MA5 / MA10 / MA20 / MA60 四条简单移动平均线，逐项叠加得分：

| 条件 | 得分 |
|------|------|
| 收盘价 > MA5 | +1 |
| 收盘价 > MA10 | +1 |
| 收盘价 > MA20 | +1.5 |
| 收盘价 > MA60 | +1.5 |
| MA5 近 3 日上行 | +1 |
| MA10 近 3 日上行 | +1 |
| MA5 > MA10 > MA20（多头排列） | +3 |

多头排列（短期均线依次在长期均线上方）是最核心的趋势确认信号，单独给予 3 分。最终取 \[0, 10\] 区间。

### 2. MACD（权重 12，原始分 0\~10）

计算标准 MACD（快线 EMA12，慢线 EMA26，信号线 EMA9）：

- **DIF** = EMA(12) − EMA(26)
- **DEA** = EMA(DIF, 9)
- **柱状线** = 2 × (DIF − DEA)

| 条件 | 得分 |
|------|------|
| 柱状线 > 0（多头区间） | +3 |
| 柱状线刚由负转正（金叉当日） | +3 |
| 柱状线较前一日递增 | +2 |
| DIF > DEA | +2 |

金叉当日同时满足"柱状线 > 0"和"由负转正"，可拿 6 分，反映强烈的趋势反转信号。

### 3. 成交量（权重 13，原始分 0\~10）

| 条件 | 得分 |
|------|------|
| 5 日均量 > 10 日均量 | +3 |
| 当日成交量 > 5 日均量 | +2 |
| 收盘价上涨 **且** 成交量放大（量价齐升） | +3 |
| 当日量 / 5 日均量 在 1.0\~3.0 倍（温和放量） | +2 |
| 当日量 / 5 日均量 ≥ 3.0 倍（异常放量，可能主力出货） | −2 |

关键点：温和放量配合价格上涨是健康信号；暴量反而扣分，因为可能意味着主力在高位派发。

### 4. 筹码分布（权重 12，原始分 0\~10）

使用最近 60 个交易日的量价数据，模拟筹码分布：

**算法原理**：将价格区间均匀分成 100 个分箱，每个交易日的成交量按三角分布（以收盘价为峰值）分配到对应价格分箱中。越早的交易日成交量会以 0.97 的衰减因子逐日递减，模拟筹码因换手而流失。

最终输出三个指标：

| 指标 | 含义 |
|------|------|
| `above_ratio` | 当前价上方筹码占比，越低上涨阻力越小 |
| `profit_ratio` | 获利盘比例（当前价下方筹码占比） |
| `concentration_90` | 90% 筹码所在价格宽度 / 当前价，越小筹码越集中 |

评分规则：

| 条件 | 得分 |
|------|------|
| 上方筹码 < 15% | +4 |
| 上方筹码 15%\~30% | +3 |
| 上方筹码 30%\~50% | +1 |
| 上方筹码 > 70% | −1 |
| 获利盘 60%\~85%（最健康区间） | +3 |
| 获利盘 50%\~60% | +2 |
| 获利盘 > 90%（过热） | +1 |
| 获利盘 < 30%（大面积套牢） | −1 |
| 筹码集中度 < 15% | +3 |
| 筹码集中度 15%\~25% | +2 |
| 筹码集中度 25%\~35% | +1 |

### 5. 动量（权重 10，原始分 0\~10）

衡量近期价格涨势强弱：

| 条件 | 得分 |
|------|------|
| 5 日涨幅 1%\~8%（温和上涨） | +4 |
| 5 日涨幅 0%\~1% | +2 |
| 5 日涨幅 > 8%（短期涨太多） | +1 |
| 10 日涨幅 2%\~15% | +3 |
| 10 日涨幅 0%\~2% | +1 |
| 当日阳线（收盘 > 开盘） | +3 |

温和、持续的上涨比急速拉升得分更高，体现"稳健上升趋势"的偏好。

### 6. 布林带（权重 10，原始分 0\~10）

使用 20 日布林带（中轨 = MA20，上下轨 = 中轨 ± 2 倍标准差），通过价格在带内的相对位置 `pos = (价格 − 下轨) / (上轨 − 下轨)` 评分：

| 条件 | 得分 |
|------|------|
| pos 在 0.4\~0.7（中轨附近偏强） | +5 |
| pos 在 0.1\~0.4（下轨附近反弹） | +4 |
| pos > 0.9（触及上轨，超买风险） | −2 |
| 价格向上突破中轨（前一日在中轨下，今日站上） | +5 |

突破中轨是重要的趋势转折信号，与中轨附近的位置分同等重要。

### 7. RSI（权重 9，原始分 0\~10）

使用 14 日 RSI，公式为 `RSI = 100 − 100/(1 + 平均涨幅/平均跌幅)`：

| 条件 | 得分 |
|------|------|
| RSI 30\~40（超卖反弹区，最佳买点） | +7 |
| RSI 40\~60（中性区间） | +5 |
| RSI 20\~30（深度超卖，可能仍在下跌） | +4 |
| RSI > 80（超买） | −3 |
| RSI 出现 V 形拐头（前日是近期低点） | +3 |

RSI 在 30\~40 给予最高分，因为此时既处于超卖区域又开始企稳，是概率最高的反弹买点。

### 8. KDJ（权重 9，原始分 0\~10）

标准 KDJ 指标（N=9, M1=3, M2=3），J = 3K − 2D：

| 条件 | 得分 |
|------|------|
| K 上穿 D（金叉当日） | +6 |
| K > D（金叉后持续） | +3 |
| J 值在 20\~80（健康区间） | +2 |
| J 值从 < 30 开始回升（低位拐头） | +2 |

KDJ 金叉是短线最敏感的买入信号之一，单日金叉给 6 分（含 K > D 的 3 分则共 6 分）。

### 9. 换手率（权重 10，原始分 0\~10）

| 条件 | 得分 |
|------|------|
| 当日换手率 2%\~8%（适中） | +5 |
| 当日换手率 1%\~2%（偏低但可接受） | +3 |
| 当日换手率 > 15%（异常活跃，风险信号） | −2 |
| 换手率 / 5 日均换手 在 1.0\~2.5 倍（温和放大） | +5 |
| 换手率 / 5 日均换手 ≥ 2.5 倍 | +1 |

换手率过高和过低都不理想——过低说明市场关注度不足，过高可能是短线资金博弈。

## 二、止盈止损预测算法

对最终入选的 Top 10 股票，综合三种方法计算止损和止盈参考价位。

### 核心指标：ATR（平均真实波幅）

ATR 衡量近 14 日的平均价格波动幅度：

```
真实波幅 TR = max(当日最高−最低, |最高−昨收|, |最低−昨收|)
ATR = TR 的 14 日简单移动平均
```

ATR 越大说明该股波动越剧烈，止盈止损区间应相应放宽。

### 止损价（取三者中的最高值，即最保守方案）

| 方法 | 计算方式 | 逻辑 |
|------|----------|------|
| ATR 止损 | 现价 − 2.0 × ATR | 波动率兜底，给予 2 倍 ATR 的回撤空间 |
| 支撑位止损 | 近 20 日最低价 × 0.99 | 跌破近期支撑即离场 |
| 布林下轨止损 | 布林带下轨值 | 跌破下轨意味着趋势可能反转 |

取三者中的**最大值**作为止损价——这是最保守的策略，确保不会因单一方法的噪声而过早止损。若计算出的止损价 ≥ 现价（极端情况），则回退到现价 × 0.95。

### 止盈价（分两档）

**止盈①（短线目标）**：

| 方法 | 计算方式 |
|------|----------|
| ATR 目标 | 现价 + 1.5 × ATR |
| 布林中轨 | MA20 |

取二者中的较大值。若结果 ≤ 现价则回退到现价 × 1.03。

**止盈②（波段目标）**：

| 方法 | 计算方式 |
|------|----------|
| ATR 目标 | 现价 + 3.0 × ATR |
| 布林上轨 | MA20 + 2σ |
| 近期阻力 | 近 20 日最高价 |

取三者中的最大值。若结果 ≤ 止盈①则回退到止盈① × 1.03。

### 使用建议

- **止盈①** 适合短线操作，到达后可考虑减仓 50%
- **止盈②** 适合波段持有，到达后可考虑全部离场
- **止损价** 是刚性底线，跌破即无条件离场
- 所有价位仅为参考，实际操作应结合盘面变化

## 三、预筛选机制

在对所有股票做完整评分之前，先用实时行情做快速筛选以提升效率：

| 条件 | 预筛分 |
|------|--------|
| 涨跌幅在 −2% \~ +5% | +3 |
| 涨跌幅 > 0（当日上涨） | +2 |
| 成交额 > 5000 万（流动性充足） | +2 |
| 当日阳线（现价 > 开盘价） | +2 |
| 开盘价与昨收相差 < 3%（无大幅跳空） | +1 |

按预筛分降序排列，保留前 200 只进入详细评分阶段。

### 基础过滤规则

在预筛选之前，已排除以下股票：

- ST / \*ST / 退市警示股
- 北交所（8 开头）和科创板（688 开头）
- 股价 < 3 元 或 > 100 元
- 停牌（成交量 = 0）
- 涨跌停（涨跌幅绝对值 ≥ 9.8%）

## 项目结构

```
stock/
├── main.py            # 主程序入口
├── config.py          # 配置参数（价格区间、权重、请求头等）
```

## 快速使用

### 1. 创建并激活虚拟环境

```bash
python -m venv stock_sentinel
```

**Windows PowerShell：**

```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\stock_sentinel\Scripts\activate
```

**Windows CMD：**

```cmd
stock_sentinel\Scripts\activate.bat
```

**macOS / Linux：**

```bash
source stock_sentinel/bin/activate
```

激活成功后，终端提示符前会出现 `(stock_sentinel)` 前缀。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 运行选股

```bash
python main.py
```

运行结束后会在终端打印推荐排名，并在 `output/` 目录下自动保存 CSV 文件（如 `output/stock_picks_20260224.csv`）。

## 配置说明

编辑 `config.py` 可调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TOP_N` | 10 | 推荐股票数量 |
| `MIN_PRICE` / `MAX_PRICE` | 3.0 / 100.0 | 股价过滤区间（元） |
| `HISTORY_DAYS` | 120 | 历史 K 线天数 |
| `RETRY_TIMES` | 2 | 网络请求重试次数 |
| `PRE_SCREEN_TOP` | 200 | 预筛选保留候选数量 |
| `SINA_BATCH_SIZE` | 800 | 新浪行情每批请求股票数 |
| `SCORE_WEIGHTS` | (见文件) | 各评分维度权重（总和 = 100） |

### 如何新增评分维度

1. 在 `indicators.py` 中实现新指标的计算函数
2. 在 `scoring.py` 的 `score_stock()` 中添加新维度的 0\~10 评分逻辑
3. 在 `config.py` 的 `SCORE_WEIGHTS` 中添加新维度的 key，同时调低其他维度的权重使总和仍为 100
